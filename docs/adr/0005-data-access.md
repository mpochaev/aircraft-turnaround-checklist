# ADR-0005. Доступ к базе через JdbcClient и SQL

Статус: предложено 27.10.2026. Если большинство разработчиков хочет Spring Data JPA, решение нужно поменять до 31.10, пока кода мало.

## Контекст

Схема базы уже написана на SQL и проверена. В ней четыре схемы, представления, jsonb, проверки CHECK и триггер журнала. Схемой управляет Flyway.

## Варианты

- **JdbcClient (Spring JDBC)**: SQL пишем сами, результат раскладываем в записи (record) или Map.
- **Spring Data JPA (Hibernate)**: классы-сущности, репозитории, меньше SQL для простых операций.

## Решение

JdbcClient. Запросы видны прямо в коде и совпадают с моделью данных. Таблица супервайзера, показатели и журнал всё равно требуют своего SQL. Знать нужно только SQL, без правил загрузки связей Hibernate. В `shared.jdbc.Rows` есть помощник, который приводит timestamp, date и jsonb к виду для JSON.

## Последствия

- Простые вставки и обновления пишем руками. Пример есть в `log.internal.JdbcAuditLog`.
- Структура таблиц меняется только миграциями Flyway, автоматическое создание таблиц отключено.
