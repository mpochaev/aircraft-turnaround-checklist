# ADR-0001. Стек: Java 21 и Spring Boot 4.1, PostgreSQL 16, Maven

Статус: принято на паре 23.10.2026.

## Контекст

Преподаватель стек не задаёт, требует только, чтобы результат был проверяемым. В группе все прошли курс веб-разработки на Java и Spring, у большинства есть опыт со Spring Boot. Схема базы уже написана на PostgreSQL (schema.sql 1.2). Это закреплено в «Описании архитектуры», таблица 5, и в НФТ-10.

## Решение

- Java 21 (LTS), Spring Boot 4.1, сборка Maven с wrapper (`./mvnw`), чтобы у всех была одна версия Maven.
- PostgreSQL 16, миграции Flyway. Первая миграция `V1__schema.sql` совпадает с schema.sql 1.2.
- Описание API в браузере через springdoc (`/swagger`). Оно строится по контроллерам и дополняет спецификацию API из docs/specs.
- Сборка и тесты на каждый пулреквест идут в GitHub Actions.

## Последствия

- Нужен JDK 21. Версии новее (22–25) тоже подходят, но в CI используется 21.
- Spring Boot 4 использует Jackson 3 (пакет `tools.jackson`) и Spring Security 7. В учебниках чаще встречается Spring Boot 3: аннотации и подход те же, отличаются некоторые импорты.
