# Показатели на экране «История»

Отвечает команда «Данные». Метод `GET /metrics` (спецификация API, раздел 8.2), требование ФТ-44, сценарий ПМИ 51.

## Как считается

В показатели попадают закрытые обороты, у которых время отправления ВС приходится на выбранный период (обе даты включительно, не больше 92 дней). Отменённые и незакрытые обороты не считаются.

| Плитка | Поле ответа | Как считается |
|---|---|---|
| Оборотов закрыто | `turnaroundsClosed` | число закрытых оборотов |
| Среднее время оборота | `avgTurnaroundMin` | среднее от постановки до отправления ВС, в минутах с округлением |
| Операций в срок | `onTimeShare` | доля выполненных операций, у которых фактическое окончание не позже планового |
| Чаще всего отстаёт | `topLateOperations` | пять операций, которые чаще других закончились позже плана; среднее отставание в минутах |
| Частый код задержки | `topDelayCodes` | пять кодов задержки, которые чаще других стоят у операций этих оборотов |

Отставание считается в целых минутах с округлением вверх: операция, закончившаяся на 30 секунд позже плана, опоздала на 1 минуту.

Данные берутся из представлений `ops.v_turnaround_result` и `ops.v_operation_result` (миграция `V202610281200`).

## Ручная проверка (сценарий 51)

Выполните запрос в Adminer за тот же период и с тем же типом ВС, что выбран на экране, и сравните с плитками. Даты и тип подставьте свои.

```sql
with t as (
    select t.id, t.on_block_at, t.off_block_at
    from ops.turnaround t
    join ref.aircraft ac on ac.id = t.aircraft_id
    join ref.aircraft_type ty on ty.id = ac.aircraft_type_id
    where t.status = 'closed'
      and t.off_block_at >= '2026-10-22' and t.off_block_at < '2026-10-29'   -- период, второй день плюс один
      and ty.code = 'A320'                                                   -- уберите строку для всех типов
)
select count(*)                                                        as "оборотов закрыто",
       round(avg(extract(epoch from off_block_at - on_block_at) / 60)) as "среднее время, мин",
       (select round(avg(case when e.actual_end <= e.planned_end then 1.0 else 0 end), 2)
          from ops.operation_exec e
         where e.turnaround_id in (select id from t) and e.status = 'done')   as "доля в срок"
from t;
```
