# Дизайн-система

На паре 23.10 договорились о едином оформлении, чтобы у четырёх команд не получилось четыре разных интерфейса. Основа взята с согласованных макетов (docs/specs, «Макеты интерфейса»): белый фон, чёрный текст, тонкие серые рамки, скруглённые кнопки, цвет только у статусов.

Живая витрина всех компонентов: http://localhost:8080/styleguide.html.

## Подключение

```html
<link rel="stylesheet" href="/css/tokens.css">   <!-- цвета, размеры -->
<link rel="stylesheet" href="/css/ui.css">       <!-- компоненты -->
...
<header class="app-header"></header>
<main class="page">...</main>
<script type="module">
    import { startPage } from '/js/layout.js';
    const me = await startPage({ active: 'turnarounds' });  // вход, шапка, меню по правам
</script>
```

Готовые страницы для образца: `supervisor/turnarounds.html` (таблица супервайзера), `technician/checklist.html` (экран планшета), `ref/index.html` (список и таблица).

## Правила

1. **Цвета только из `tokens.css`.** Интерфейс чёрно-белый. Цвет означает только статус операции (таблица 3 ЧТЗ), и рядом всегда есть текст или время (НФТ-7).
2. **Экраны техника работают на планшете.** У `<body>` ставим класс `touch`: кнопки высотой 48 пикселей (больше 1 см), шрифт 16 пикселей (НФТ-6).
3. **Одна главная кнопка на экран** (`btn-primary`), остальные обычные (`btn`).
4. **Недоступную кнопку не прячем.** Она остаётся на месте неактивной, а в `title` или рядом объясняется причина: «ждёт: заправка, питание» (ФТ-30).
5. **Время пишем ЧЧ:ММ, дату ДД.ММ.ГГГГ.** Используйте функции `time()` и `date()` из `/js/format.js`.
6. **Тексты по-русски, как в ЧТЗ:** «Постановка ВС», «Начать», «Завершить», «Проблема», «Решено», «Не требуется», «Отправление ВС».
7. **Ошибки показываем так.** Ошибка поля выводится под полем (`field invalid` + `field-error`), поле берётся из `details[].field`. Остальные ошибки выводит `showError()` вместе с requestId.
8. **Таблицы и чек-лист обновляются раз в 15 секунд** функцией `every(15, ...)` с `background: true`.

## Токены

| Токен | Значение | Где |
|---|---|---|
| `--c-text` | #000000 | текст, рамки кнопок и полей |
| `--c-muted` | #555555 | подписи, второстепенный текст |
| `--c-border` | #8c8c8c | рамки таблиц и панелей |
| `--c-surface` | #f5f5f5 | шапка, заголовки таблиц |
| `--c-selected` | #e8e8e8 | выбранный пункт списка, активная вкладка |
| `--st-not-started` | #eeeeee | не начата |
| `--st-in-progress` | #fff3b0 | в работе |
| `--st-done` | #d9f2d9 | выполнена в срок |
| `--st-late` | #ffdcae | отставание до 10 минут |
| `--st-late-critical` | #f7bcbc | отставание больше 10 минут |
| `--st-problem` | #dcd0f0 | проблема |
| `--st-not-required` | #ffffff | не требуется |
| `--fs-base` | 14 px, на планшете 16 px | основной шрифт |
| `--control-h` | 32 px, на планшете 48 px | высота кнопок и полей |
| `--radius` | 8 px | скругление кнопок |

## Компоненты

| Компонент | Классы | Пример на странице |
|---|---|---|
| Шапка с меню | `app-header`, `app-nav`, `app-user` | рисует `startPage()` |
| Заголовок страницы | `page-header`, `actions` | все страницы |
| Панель фильтров | `toolbar` | таблица оборотов, журнал |
| Кнопки | `btn`, `btn-primary`, `btn-wide` | чек-лист |
| Поля | `field`, `input`, `select`, `textarea`, `field-error`, `invalid` | styleguide |
| Таблица | `table`, `table-wrap`, `clickable`, `center`, `num` | все списки |
| Ячейка статуса | `st-not_started`, `st-in_progress`, `st-done`, `st-late`, `st-late_critical`, `st-problem`, `st-not_required` | чек-лист, таблица оборотов |
| Значок | `badge` + класс статуса | styleguide |
| Список слева | `split`, `list`, `selected` | справочники |
| Вкладки | `tabs`, `tab`, `active` | пользователи и заявки |
| Сообщение | `alert`, `alert-error`, `empty` | `showError()` |
| Подсказка при наведении | атрибут `data-tip` | ячейка таблицы супервайзера |
| Окно подтверждения | `<dialog class="dialog">` | «Подтвердить готовность ВС?» |
| Легенда статусов | `legend` | под таблицей супервайзера |
| Заглушка «в разработке» | `wip` | страницы, которые ещё делаются |

Новый компонент добавляем в `ui.css` и на `styleguide.html` отдельным пулреквестом с меткой `design`, чтобы его увидели все команды.
