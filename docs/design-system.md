# Дизайн-система

На паре 23.10 договорились о едином оформлении, чтобы у четырёх команд не получилось четыре разных интерфейса. Расположение элементов взято с согласованных макетов (docs/specs, «Макеты интерфейса»). Вид простой и чёрно-белый: светло-серый фон, белые карточки, чёрный текст, скруглённые углы, системный шрифт. Цвет есть только у статусов операций.

Живая витрина всех компонентов: http://localhost:8080/styleguide.html. Ту же страницу одним файлом, который открывается без запуска приложения, делает скрипт:

```bash
python tools/design/export_styleguide.py            # tools/design/out/design-system.html
```

За дизайн-систему отвечает команда «Данные».

## Подключение

```html
<link rel="stylesheet" href="/css/tokens.css">   <!-- цвета, размеры -->
<link rel="stylesheet" href="/css/ui.css">       <!-- компоненты -->
...
<header class="app-header"></header>
<main class="page">...</main>
<script type="module">
    import { startPage } from '/js/layout.js';
    const me = await startPage({ active: 'turnarounds' });  // вход, шапка, меню по правам
</script>
```

Готовые страницы для образца: `supervisor/turnarounds.html` (таблица супервайзера), `technician/checklist.html` (экран планшета), `ref/index.html` (список и таблица).

## Правила

1. **Цвета только из `tokens.css`.** Интерфейс чёрно-белый. Цвет означает только статус операции (таблица 3 ЧТЗ), и рядом всегда есть текст или время (НФТ-7). Оранжевый не используем: отставание до 10 минут светло-красное, чтобы не путалось с жёлтым «В работе». При следующей правке ЧТЗ таблицу 3 поменяем.
2. **Экраны техника работают на планшете.** У `<body>` ставим класс `touch`: кнопки высотой 48 пикселей (больше 1 см), шрифт 16 пикселей (НФТ-6). Класс работает и на отдельном блоке, например на окне `dialog`.
3. **Одна главная кнопка на экран** (`btn-primary`), остальные обычные (`btn`).
4. **Недоступную кнопку не прячем.** Она остаётся на месте неактивной, а в `title` или рядом объясняется причина: «ждёт: заправка, питание» (ФТ-30).
5. **Время пишем ЧЧ:ММ, дату ДД.ММ.ГГГГ.** Используйте функции `time()` и `date()` из `/js/format.js`.
6. **Тексты по-русски, как в ЧТЗ:** «Постановка ВС», «Начать», «Завершить», «Проблема», «Решено», «Не требуется», «Отправление ВС».
7. **Ошибки показываем так.** Ошибка поля выводится под полем (`field invalid` + `field-error`), поле берётся из `details[].field`. Остальные ошибки выводит `showError()` вместе с requestId.
8. **Таблицы и чек-лист обновляются раз в 15 секунд** функцией `every(15, ...)` с `background: true`.

## Общие части страниц

Функции из `/js/ui.js`, чтобы каждая команда не писала их заново:

- `confirmDialog({ title, text, ok, touch })`: окно подтверждения, возвращает true или false;
- `showFieldErrors(form, err)`: ошибки проверки из `details[].field` под полями формы, поле ищется по `name`;
- `refSelect(select, dictionary, opts)`: выпадающий список из справочника, только активные записи;
- `pager(container, { page, size, total, onPage })`: листалка страниц под таблицей.

Журнал на экранах выводится через `/js/journal.js`: виды действий `ACTION_TYPES`, подписи значений `describeValue()`, строки таблицы `logRows()`.

Новый компонент добавляем в `ui.css` и на `styleguide.html` отдельным пулреквестом с меткой `design`, чтобы его увидели все команды. После слияния обновляем выгрузку скриптом `export_styleguide.py`.
