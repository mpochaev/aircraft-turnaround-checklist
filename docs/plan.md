# Общий план команд

План собран из заданий команд ([docs/teams](teams/README.md)). Он нужен, чтобы команды шли вровень: никто не ждёт другого в последний момент и никто не делает чужую работу. Если команда не успевает свою строку, лидер пишет в общий чат до пары, а не на паре.
