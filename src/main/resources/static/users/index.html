Пользователи

Страница в разработке. Команда «Авторизация».

Что должно быть на экране: вкладки «Пользователи», «Заявки», «Роли и права»; создание сотрудника, роли, сброс пароля, разблокировка, решения по заявкам (ФТ-9, ФТ-11, ФТ-15).

Методы API: GET/POST /users, PATCH /users/{id}, GET /change-requests, PATCH /change-requests/{id}, GET/POST /roles, PATCH /roles/{id}, GET /permissions (спецификация, раздел 5). Учётные записи и роли ведёт Keycloak, см. docs/adr/0002-keycloak.md.

Макет: документ «Макеты интерфейса», рисунки 8 и 9. Компоненты и правила оформления: /styleguide.html.
