Дизайн-система

В приложение

Все экраны собираются из этих компонентов. Стили: /css/tokens.css и /css/ui.css. Правила: docs/design-system.md. Своих цветов и шрифтов на страницах не заводим.

Цвета

Интерфейс чёрно-белый. Цвет означает только статус операции, и рядом с цветом всегда есть текст (НФТ-7).

Кнопки

Классы: btn, btn btn-primary (одна на экран), btn-wide. Недоступная кнопка остаётся на месте с подсказкой title, почему она неактивна.

Поля

Ошибка проверки показывается под полем (ФТ-18): у field класс invalid, текст в field-error, поле берётся из details[].field ответа API.
