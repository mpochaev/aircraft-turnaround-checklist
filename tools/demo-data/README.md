# Демонстрационные данные

Трое суток работы SVO, около 150 оборотов в сутки. Обороты до момента «сейчас» закрыты, около него в работе, после него запланированы. Правила генерации записаны на листе «Описание» в Excel-файле, который создаёт скрипт.

```bash
pip install openpyxl                                   # нужен только для Excel
python tools/demo-data/generate_demo_data.py --now 11:00          # сегодня, «сейчас» 11:00
docker compose -f infra/docker-compose.yml exec -T db psql -U checklist -d checklist < tools/demo-data/out/demo_data.sql
```

Параметры: `--date` (последний день, по умолчанию сегодня), `--now`, `--days` (по умолчанию 3), `--seed`.

Загружайте после первого запуска приложения: схему создаёт Flyway. Чтобы загрузить заново, пересоздайте базу: `docker compose -f infra/docker-compose.yml down -v`, затем `up -d` и запуск приложения.
