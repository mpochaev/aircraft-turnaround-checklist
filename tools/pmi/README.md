# Проверки ПМИ в базе

Сценарии, которые проверяются прямо в базе данных, а не через экраны. Запросы выполняются в Adminer (http://localhost:8181) или psql. Результат записывается в протокол испытаний. Отвечает команда «Данные».

| Файл | Сценарий | Что проверяем |
|---|---|---|
| `49_log_protection.sql` | 49, ФТ-41 | запись журнала нельзя изменить, удалить и очистить |
| `50_block_log_on.sql`, `50_block_log_off.sql` | 50, ФТ-2 | изменение без записи в журнал не сохраняется |
| `56_old_data.sql` | 56, ФТ-45 | плановое удаление данных старше 3 лет |

Сценарий 55 (восстановление из копии) описан в `docs/backup.md`, сценарий 51 (ручной расчёт показателей) в `docs/metrics.md`.
